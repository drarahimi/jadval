# 🧩 جدولانه — جدول کلمات متقاطع هوشمند و کلاسیک فارسی

> **👤 کاری از افشین رحیمی | ❤️ تقدیم به پدر عزیزم**

**جدولانه (Jadvalaneh)** یک برنامه وب پیشرفته، زیبا و هوشمند برای ساخت و حل جدول‌های کلمات متقاطع کلاسیک به زبان فارسی است. این برنامه از یک موتور حل کلمات بر پایه الگوریتم‌های CSP (محدودیت‌های متقاطع) و الگوی تقارن ۱۸۰ درجه روزنامه‌ای بهره می‌برد.

---

## ✨ ویژگی‌های کلیدی

- 📰 **موتور جدول متقاطع کلاسیک (100% Dual Intersection)**: تولید جدول‌های متقاطع روزنامه‌ای با تقارن ۱۸۰ درجه در ابعاد مختلف ($7\times7$، $9\times9$، $11\times11$ و $13\times13$). تمامی خانه‌های سفید دارای تقاطع دوطرفه (افقی و عمودی) هستند.
- ⚡ **الگوریتم حل فوق‌سریع MRV**: تولید و جانمایی بیش از ۳۰ تا ۵۰ کلمه متقاطع در کمتر از ۵ میلی‌ثانیه بدون خانه‌های بلااستفاده.
- 💡 **سیستم راهنمایی هوشمند**: راهنمایی حرف، کلمه و شناسایی خطاها با رنگ قرمز بدون فاش کردن پاسخ.
- ⏱️ **زمان‌سنج و ثبت رکوردها**: زمان‌سنج زنده با قابلیت توقف/ادامه و ثبت بهترین زمان حل جدول.
- 📅 **جدول اختصاصی روزانه**: تولید جدول ثابت بر اساس تاریخ روز برای همه کاربران.
- 🏷️ **جدول‌های موضوعی**: امکان انتخاب دسته‌بندی موضوعی (علوم، جغرافیا، تاریخ، فرهنگ و خوراک‌ها).
- 🖼️ **خروجی مستقیم عکس PNG**: امکان دانلود جدول فعال به عنوان تصویر PNG با کیفیت بالا.
- 📚 **ساخت کتابچه جدول و خروجی PDF**: ساخت کتابچه با جلد اختصاصی (*"تقدیم به پدر عزیزم"*) و پاسخ‌نامه.
- 🌙 **حالت شب و درشت‌خط**: قابلیت سوئیچ بین تم تاریک/روشن و حالت درشت‌خط برای کم‌بینایان.
- 📥 **پشتیبان‌گیری بانک کلمات**: قابلیت دانلود و بارگذاری فایل JSON برای مدیریت بانک کلمات شخصی.
- 🎉 **انیمیشن جشن و نورافشانی**: نورافشانی کاغذهای رنگی (Confetti) هنگام حل کامل و صحیح جدول.
- 📱 **برنامه وب قابل نصب (PWA)**: امکان نصب مستقیم روی صفحه اصلی گوشی‌های اندروید (Android) و آیفون (iOS) همراه با پشتیبانی از کارکرد آفلاین.

## 🚀 راهنمای اجرا و استفاده

### اجرا روی کامپیوتر
این پروژه نیازی به نصب هیچ پیش‌نیازی ندارد! کافی است فایل `index.html` را در مرورگر خود باز کنید.

همچنین می‌توانید با یک دستور ساده سرور محلی اجرا کنید:
```bash
# با استفاده از Node.js
npx serve .

# یا با استفاده از Python
python -m http.server 8000
```

### نصب روی گوشی (PWA)
- **اندروید (Chrome / Edge)**: منوی مرورگر (**⋮**) ➔ انتخاب **افزودن به صفحه اصلی** یا **نصب برنامه** (Add to Home screen / Install app).
- **آیفون و آيپد (Safari)**: دکمه اشتراک‌گذاری (**↑**) ➔ انتخاب **Add to Home Screen** (افزودن به صفحه اصلی).

## 🛠️ تکنولوژی‌های استفاده‌شده

- **HTML5 & CSS3**: متغیرهای CSS، Grid Layout، Flexbox و دستورات اختصاصی `@media print`.
- **JavaScript (ES6+)**: الگوریتم‌های CSP، MRV Backtracking Solver، PRNG و Canvas API.
- **PWA Ecosystem**: `manifest.json` و `sw.js` (Service Worker) جهت کارکرد آفلاین و نصب PWA.
- **Vazirmatn Font**: فونت استاندارد و زیبای وزیرمتن برای تایپوگرافی فارسی.
